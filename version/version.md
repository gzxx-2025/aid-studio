# 版本发布说明

## 未发布

## v2.2.0（2026-09-23）

### 运行稳定性

- 升级 Spring Boot 依赖至 3.5.9，修复并发请求与定时任务同时解析注解时可能出现的缓存死锁和接口无响应。无需 SQL。

### 错误处理

- 错误处理页增加实时授权门禁：签名发布配置与当前服务器出口 IP 经官方确认后才可查看诊断、管理密钥、验证连接或发送报告；授权异常、撤销和查询失败立即锁定，仅保留本地采集开关与授权申请、查询。申请凭证加密保存，主动刷新跟随签名发布配置地址。无需 SQL。
- 供应商返回结构化 `Arrearage` 欠费错误时优先识别为模型商户额度不足，不再被通用 `Access denied` 文案误判为密钥失效；真实鉴权失败与 HTTP 401/403 仍保持原分类。无需 SQL。
- 增加默认关闭的错误诊断，关联请求标识、原始供应商响应及浏览器证据；完整保留文本，过滤敏感认证字段与智能体提示词，媒体二进制仅保留引用说明。本地记录保留 7 天。
- 后台可申请服务器出口 IP 白名单，人工审核通过后才允许上报和连接验证；关闭采集时仍可查看、提交申请。配置与临时资料使用专用加密存储，不通过通用配置接口展示。
- 上报采用签名公共配置与混合加密，独立有界队列提交，展示官方处理终态；同一报告保留原加密包用于幂等恢复，不重试业务生成请求。
- 数据库新增诊断记录、发送队列和异步任务关联表及菜单权限。先执行 `sql/v2.2.0.sql` 再启动程序；新安装同步 `sql/aid-init.sql`。未开启采集时不记录诊断正文。

### 图片编辑工具

- 图片编辑业务目录区分重绘、物体擦除、扩图和打光；业务模型池引用模型能力，独立模型定义保留原有能力与计费配置。候选模型与默认项由业务配置决定，不静默替换用户选择的模型。
- 按业务查询模型时补充默认模型编码和可选能力列表，客户端可按能力展示参数与计费信息；返回数据不包含供应商路由、固定私有参数或成本配置。
- 模型管理增加官方图片能力模板预览，保留已配置能力、价格和参数约束，仅补齐缺项；新增能力默认停用，需核验协议、计费和实际效果后启用。
- 图片编辑协议支持独立蒙版及选区语义转换、目标画布扩展和灯光编辑参数；扩图与区域编辑结果统一保存透明 PNG，复用现有任务和存储体系。
- 图片编辑多结果按任务内序号幂等保存，逐项完成像素保护和平台存储后再对外提供结果；存储补偿复用原任务，不重复调用生成模型或重复扣费。
- 复用媒体结果表，补充 `result_index` 与任务内唯一索引，历史记录按原主键顺序编号并保留原 ID、地址；已有对应索引的库不重新编号。升级期间暂停媒体任务写入，先执行 SQL 再启动新程序。
- 本次业务目录初始化及媒体结果扩展均为幂等变更，不新增数据库表；升级脚本见 `sql/v2.2.0.sql`，新安装同步 `sql/aid-init.sql`。不覆盖已有业务配置，不自动启用模型或改写价格。
- 修复编辑结构化模型能力时，被无关历史模型池中的失效模型编号阻断保存的问题；仅在模型池成员实际变化时重验并更新成员，能力选择仍校验唯一默认项，新增、移出和清空保护保持完整。无需 SQL。
- 模型参数校验会明确返回错误字段及必填、类型、允许值、上下限或步长要求，便于调用方直接修正错误参数；提示只包含公开能力约束，不回显请求素材或供应商内部配置。无需 SQL。
- 修复区域编辑与扩图的受保护画布尺寸被旧规格档位开关误判为不支持的问题；仅向明确声明输出尺寸参数的模型写入权威像素尺寸，普通图片规格和冲突尺寸仍按模型能力拒绝。无需 SQL。
- 图片供应商将 Base64 结果预先写入本站存储并返回相对路径时，后处理会按当前存储配置安全读取原始结果，再完成蒙版区域外像素保护；读取不携带模型网关凭证，原任务可通过存储补偿恢复且不会重复调用或计费。无需 SQL。

### 模型与媒体任务

- 角色、场景、道具形态图会按本次是否携带继承参考图明确选择文生图或图生图能力；角色设定卡固定选择图生图能力。旧版多能力图片模型在后台首次结构化保存时，会为同时承载纯文本与参考图请求的业务池保留文生图和图生图两项绑定，避免业务池默认项与真实输入不一致，或保存后出现“业务未绑定此能力”。无需 SQL。
- 模型可按需启用图片代理 URL 模板。已开启模型的系统自有图片在 Provider 提交前改用站长配置的资源访问域名，不生成对象存储临时签名且移除查询参数，再对完整地址编码并代入唯一 `{url}` 占位符；外部图片 URL 保持原值后整体编码。仅处理图片语义输入，视频、音频、文档、回调及生成结果地址保持不变。未开启模型继续使用原有对象存储临时签名链路，全部历史模型默认关闭。
- 模型新增、详情和修改接口增加 `imageUrlProxyEnabled`、`imageUrlProxyTemplate` 管理字段；模板启用时校验 HTTPS、唯一占位符、长度、账号信息及 Fragment。数据库升级见 `sql/v2.2.0.sql`，新安装结构已同步至 `sql/aid-init.sql`。
- 视频参考模式的通用场景解析与能力校验会把 `voiceId` 与 `referenceAudioVoiceIds` 识别为参考音色输入，支持只传音色 ID 或与参考图组合；参考音频文件仍按独立能力校验。无需 SQL。

### 模型能力接口

- 模型列表、按功能分组模型和项目生成设置中的模型项增加顶层 `maxPromptCharacters` 与 `maxPromptCharactersCjk`；从当前业务能力读取，未配置时明确返回 `null`，供客户端按模型展示提示词上限。无需 SQL。

### 公共资源

- 修正旧版交流二维码默认资源路径；升级仅调整仍使用错误默认值的记录，管理员自定义地址不变。数据库升级见 `sql/v2.2.0.sql`。

## v2.1.9（2026-09-21）

- TokenDance MiniMax H3 目录补齐首帧、首尾帧及多参考视频场景；已导入且未自定义场景的模型由本版 SQL 幂等补全。MiniMax H3 Max 仅保留已有证据支持的文生、首帧与首尾帧场景，不开放未证实的多参考能力。
- 安装基线与本版升级 SQL 不包含非公共模型目录的供应商预置数据；升级不会删除已有供应商记录。

### 图片处理

- 增加按原图像素裁切宫格和指定矩形区域的通用处理能力，保持原尺寸与透明通道；裁切本身不发起高清模型任务或扣除生成积分。无需 SQL。

### 通用生成任务

- 新增文本、图片、视频的持久化后异步提交能力：任务入库并预冻结后立即返回任务号，复用现有并发准入、排队、终态结算和重启补偿；线程池饱和时保留排队任务，不在请求线程执行上游调用。既有同步 Java 调用保持原语义。
- 文本任务也返回估算进度和剩余时间；估算按历史成功样本逐渐校准，默认时长可通过 `media_eta.text_p50_seconds`、`media_eta.text_p90_seconds` 配置。以上变更无数据库结构或初始化数据变更，无需 SQL。

### 服务商与模型管理

- 供应商增加“三方聚合”和“官方厂商”两种展示分类及同类排序；既有模型路由、计费和密钥保持原配置。New API 站点归入三方聚合，可填写任意站点根地址。
- New API 支持仅配置模型 Key 的手动模式，以及可选的普通用户访问令牌模式。开启后可读取本站可用分组、选择或创建本人调用 Key，并按所选分组、Key 白名单和站点实时价格获取模型目录；不需要账号密码或管理员权限。
- New API 文本模型按站点可换算价格生成 Token SKU，并在导入前实际生成；模型管理的“实际测试”可再次验证已导入的文本模型。缺少平台执行协议的模型仍保留在目录并标明阻止原因。
- New API 文本价格缺失或无法换算时默认输入、输出各 1 元/百万 Token；图片模型通过 Images 协议实际生成验证后，可按默认 1 元/张导入，后台“实际测试”沿用正式图片客户端并确认图片结果保存。默认价是平台收费设置，现有可换算文本价格保持不变；视频等未完成执行协议验收的类型仍阻止导入。本次补价与测试无数据库变更，无需新增 SQL。
- New API 按秒计价的媒体模型即使被站点标成 `openai`，也依据计价元数据阻止误导入为文本；目录展示预期默认 1 元/秒，待相应协议通过实际调用验收后才可添加。无需 SQL。
- New API 站点关闭价格页或不提供价格接口时，仍可按用户分组与调用 Key 的模型目录加载模型；价格缺失时使用平台默认价。原版 Sora 插件声明的视频模型即使失去按秒计价元数据，也不会误作为文本导入。无需 SQL。
- 数据库变更见 `sql/v2.1.9.sql`，新安装结构已同步至 `sql/aid-init.sql`；升级脚本可重复执行，不覆盖已有供应商密钥及模型配置。

### 分镜视频生成

- 分镜任务防重只按父任务快照中的 `storyboardIds` 数组判断活动分镜，不再被同一快照中的音频或其他素材 ID 误命中；已完成任务后可正常继续生成。无需 SQL。

### 配置连通性测试

- Agnes 供应商及模型的只读测试识别上游附带请求标识的“任务不存在”响应，不再误报为接口地址不存在；该测试仅确认查询鉴权，不会发起生成或验证模型出片能力。

### 请求参数校验

- 请求参数校验失败时返回业务码 `400` 和原有提示；日志只记录校验对象与字段，不再记录被拒绝的正文或整段堆栈。

### 内置图片资源

- 服务商与模型未上传专属图标时使用程序内置的供应商品牌图标，上传的自定义图标始终优先。默认头像和行为式验证码背景随程序打包，未上传时可直接使用，不依赖外部图片 CDN。
- 升级脚本仅将旧版内置供应商图标、复用这些图标的模型图片及默认背景地址切换到本地路径，保留已有自定义图片；新安装基线同步使用本地路径。后台与 Web 用户端需同时部署对应静态资源。

### 图片模型

- 增加 Topaz Labs 官方 Image API 协议适配与 7 个图片放大模型的停用目录。模型按各自官方标识、输入素材、目标像素尺寸、支持的处理参数及输出像素上限配置；不以页面风格或固定放大倍率限制模型能力。复用现有任务轮询、结果转存和计费链路；供应商密钥和真实联调完成前不得启用。
- 图片 SKU 可配置每个价格单位覆盖的输出像素数，预扣时按目标输出像素向上取整计算单张价，结算沿用该任务快照。Topaz 停用目录补入官方积分成本换算的可编辑初始价格，不覆盖已有运营报价；系统统一倍率继续生效。
- 原图地址在统一输入预检时校验；任务提交前生成的临时签名地址不重复按原始地址规则校验，避免合法素材被误拒绝。
- 数据库增量见 `sql/v2.1.9.sql`，新安装基线同步更新。迁移可重复执行，不覆盖已有供应商或同编码模型配置。

## v2.1.8（2026-09-18）

## v2.1.5（2026-09-15）

### 模型与文本计费

- GPT-5.6 模型显示名明确为 GPT-5.6 Sol，平台稳定编码继续保留 `gpt-5.6` 以兼容既有 Skill 和业务引用，真实上游模型及结构化路由统一改为 `gpt-5.6-sol`。
- GPT-5.6 Sol 内置计费基线按官方当前价格拆分为不超过 272K 与超过 272K 两档，分别覆盖输入、缓存读取、缓存写入、可见输出和推理 Token；条件迁移仅修正已知旧内置价格，不覆盖站长自定义 SKU。
- 文本模型失败计费改用供应商无关的调用证据：请求未发送，或上游返回标准且语义明确的最终拒绝状态且没有任何真实用量时全额解冻；已返回用量按实际用量结算，超时、断链、私有状态码、5xx 和结果不确定场景继续保守结算。同步、流式、冻结补偿、父任务聚合和 Skill Runtime 共用同一规则。
- OpenAI 兼容（含 DeepSeek）、Gemini 和 TokenDance 文本协议的密钥、地址及端点配置在预冻结前校验；排队任务提交前再次校验，避免本地配置错误进入可能计费边界。

### Web 用户端

- 新增账号安全设置中心，并优化设置面板的表单间距与操作按钮层级。
- 修复素材提示词编辑、登录反馈、生成后提示词保留以及弹窗提示词格式回显问题；确认弹窗的图标与标题保持同行展示，提交区报价与对话生成操作互斥呈现。
- 修复无需生成分镜图的创作模式仍会打开分镜图编辑弹窗的问题；跨步骤返回分镜设计时会按当前创作模式决定是否打开编辑器，并清理模式切换后残留的开窗意图。
