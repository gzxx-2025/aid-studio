## v2.2.0（2026-09-23）

### 错误处理

- 错误处理页仅在官方实时确认当前服务器出口 IP 授权后开放密钥、错误记录和诊断提交；未授权或查询异常时立即锁定并清除已显示资料，仍可开关本地采集、申请和刷新授权。申请区显示申请号、审核说明及查询凭据保存状态；刷新时强制核验发布配置与授权。无需 SQL，需配套服务端接口升级。
- 新增统一错误处理页面，集中维护采集开关、加密密钥、出口 IP 白名单申请、原始记录与异步上报结果。关闭采集后仍可申请和刷新白名单。
- 支持按需填写排查资料、显式授权连接验证、查看完整过滤后 JSON 和人工重试未确认报告；同一请求合并并发提交，防止重复申请、发送和轮询。
- 本端无需 SQL；菜单及权限由服务端同批次诊断数据库升级提供，需配套部署服务端。

### 模型管理

- 模型长列表的横向滚动条保持在当前可见表格底部，浏览多列时无需滚到列表末尾。无需 SQL。
- 修复后台侧栏折叠后仍显示内联子菜单和截断文字的问题；折叠轨仅保留一级功能图标，子菜单继续通过悬浮菜单访问。无需 SQL。
- 修复 AI 业务编排把功能启停状态显示为“是／否”的问题，列表、筛选和编辑表单统一使用“启用／停用”，避免将正常状态误解为否定状态。无需 SQL。
- AI 业务编排的候选模型按当前功能的模型大类和生成模式自动收口，停用模型不再作为新候选；保存时再次校验已选模型兼容性，避免把视频等错误媒体类型绑定到图片业务。修复分区标题内容被推到弹窗右侧的问题，标题与说明恢复在品牌竖条后显示。无需 SQL。
- 模型能力表单增加区域编辑和图片扩展能力，并提供原图、蒙版、蒙版选区语义、扩图布局及灯光参数的图形化配置。蒙版可按模型能力分别配置 PNG、JPEG 和 WebP 等允许格式；已保存的图片模型可预览并补齐官方能力，新增能力默认停用且不改动价格，预览内容在视口内滚动并始终保留应用按钮。业务模型池明确将首个可用模型标识为默认模型，其余模型按排序候选，并继续维护默认能力和业务默认参数。后台无独立 SQL，需配套服务端能力和业务绑定升级脚本。
- 模型基本信息增加可选的“上游图片访问兼容”配置。启用后必须填写带唯一 `{url}` 占位符的 HTTPS 代理模板，页面会就地校验长度、地址、账号信息和 Fragment；系统自有图片由服务端改用站长配置的无签名资源访问地址，再代入模板。关闭时保留模板但不生效。仅配套服务端模型字段，无后台独立 SQL。
- 视频能力的时长选项按数值升序展示并按升序保存，包含连续秒数的模型不再出现预设值插队。无需 SQL。
- 视频能力将“参考音频文件”和“参考音色 ID”分开配置；关闭生成声音不会再清除独立的音色 ID 能力，避免只接受上游音色编码的协议被误显示为不支持。无需 SQL。

## v2.1.9（2026-09-21）

- SKU 价格编辑支持拖动及上下按钮调整顺序，并同步更新匹配优先级；键盘用户可用上下按钮完成同一操作。OpenAI 图片模型按像素规格推算计费档位时，编辑器不再把有效的 1K/2K/4K SKU 条件误报为未启用规格。无需 SQL。

### 模型管理

- 供应商侧栏仅分“三方聚合”和“官方厂商”两组，三方优先。两组采用互斥手风琴，默认展开三方、收起官方；搜索命中另一组时自动切换，列表过长时在组内滚动。
- 新增服务商可选择 New API 站点。关闭系统访问令牌时只填写站点地址和模型 Key，手动新增文本或图片模型只需补充真实模型标识，价格分别预填每百万 Token 1 元或每张 1 元，其余协议、能力和 SKU 自动初始化；开启后使用普通用户访问令牌选择上游分组、绑定或创建本人 Key，并从所填站点动态拉取模型。目录明确显示站点价或默认价，文本及图片模型须通过对应接口实际生成才能导入；批量选择后逐个提交，避免图片生成跨过单次网关时限；已添加的文本和图片模型提供实际生成测试，图片测试会保存结果。其他未匹配执行协议的模型继续说明阻止原因。
- 后台无需独立 SQL；需配套服务端待发布的供应商字段升级脚本。

### 视频模型能力

- 素材参数编辑器支持精确字节上限及参考视频、音频超过阈值后取片头的有效时长配置，供 DMC H3 等视频能力与服务端校验保持一致。无需后台专属 SQL。

### 内置图片资源

- 模型管理的供应商、模型图标在未设置自定义图片时使用程序内置资源；上传的自定义图片优先。系统配置展示内置默认头像和行为式验证码背景，上传后仍优先使用自定义图片。无需新增数据库表。

### 模型管理

- 聚合供应商介绍区默认收起，可按需展开目录、授权与账户操作；供应商侧栏标明当前环境已配置数量，并统一使用“聚合供应商”标记。无需服务端或数据库变更。

### 模型计费

- 图片 SKU 编辑器支持按输出像素单位输入价格和像素数，模型列表显示每单位价格与向上取整口径。Topaz 初始参考价格配置后可直接核对计费状态，修改价格仍需通过现有校验。

## v2.1.3（2026-09-13）

- 修复模型池绑定与移出把旧版生成模式误作结构化能力白名单的问题，首尾帧、多参考图及多帧等已启用能力可按业务正常维护；功能池编辑仅要求真实落入结构化能力子表的模型选择业务能力，旧配置的兼容展示能力不再生成大量空白必填项或阻止保存。新增结构化模型会按唯一默认能力初始化，既有合法选择保持不变。无需数据库变更。
- 修复图片模型“允许的生成场景”保存后丢失、既有标准场景编码因大小写不一致无法正确回显的问题；图片与视频模型仅展示各自适用的标准场景候选，并继续保留已有供应商扩展场景。无需数据库变更。

## v2.1.0（2026-09-12）

### 管理后台

- 模型编辑默认打开能力配置，分辨率、比例、时长、音画同步和参考媒体开关可直接编辑；完整能力控件继续保留。SKU 与价格提升为同级独立入口，按调用协议分别维护，避免在多层协议页签中查找。常用能力编辑仅更新对应字段，保留其他能力 JSON 与 SKU 顺序，无需数据库变更。

- 模型列表新增计费配置概览，直接展示固定价或 SKU 计费状态、启用 SKU 数量、官方原价摘要、价格缺口和单模型倍率，无需进入编辑弹窗即可核对计费完整性。
- 模型能力改用可见卡片切换并同步标明各能力的计费状态；固定价与 SKU 模式改为并列选择，SKU 编辑器增加启用数、已配价数量、单条 SKU 价格及命中条件摘要。保存继续保持 SKU 原顺序及未知计费 JSON 字段，不重建未修改配置。
- 本次仅优化后台计费配置展示与交互，无需新增服务端代码和数据库变更。

- 修复供应商余额有返回但不展示的问题：按币种余额、积分和资源包分别呈现总量及明细，保留零值和负值，显示查询时间、失败原因与明确空态。
- 上游任务默认显示全部状态，切换页签自动加载；兼容可灵与 MiniMax 状态、分页和查询范围，翻页失败保留原页，查询按账户与业务键合并并发请求。
- 余额监控显示官方单位并校验阈值单位，查询不可用不再显示正常，既有告警状态保留；查询失败时不再统一提示检查成功。无需数据库变更，需配套服务端余额响应修复。

- 优化 TokenDance 重新授权成功提示：移除官网嵌入页，改用清晰的旧 Key 清理说明与官网管理链接；授权及凭证保存逻辑保持不变。

- 模型编辑集中管理基本信息、能力与参数、调用配置、计费和业务绑定；嵌套字段、默认值、素材限制和条件规则全部使用表单控件，支持参数预览。
- 业务池绑定统一模型及所需能力；新增模型迁移预检与冲突选择，提供模板差异预览，保留已有合法自定义配置。
- 配置读取合并同请求键的进行中请求，保存期间阻止重复提交。部署本功能需配套模型能力服务端及数据库增量脚本。
- TokenDance 模型目录明确展示“不兼容 AID · 禁止导入”、原因及不可被目录刷新解除的提示，并支持按该状态筛选；批量选择和导入继续遵循服务端兼容门禁。

- 优化模型配置页的 TokenDance 推荐区域，使用本地品牌 Logo，清晰展示接入入口、账户能力和模型数量。
- 精简模型列表，移除能力、计费模式、模型接口路径、API 版本、图片类型、原价、并发和优先级展示列；模型 Logo 与名称合并展示，调整筛选、批量操作及窄屏布局。
- 本次仅调整后台页面展示，原有模型配置与接口保持兼容，无需数据库变更。
- 修复模型列表过长时无法纵向滚动的问题；TokenDance 目录支持切换每页 10、20、50、100 条，筛选与重新加载后返回首页，翻页和调整每页数量不重复请求目录接口。

### Skill 管理

- 修复 Skill 草稿只调整模型池且未打开 Schema 页签时，未挂载字段被误判为空的问题；历史空输入或输出 Schema 按合法空对象兼容，损坏的非空 JSON 仍会明确拒绝。
- 修复包含固定子 Skill 的草稿在放弃未保存修改并关闭编辑器时页面异常的问题。

### 案例广场

- 恢复案例广场审核与发布管理页面、路由和权限入口，支持查看发布快照、审核发布、驳回和下架。

### 升级说明
