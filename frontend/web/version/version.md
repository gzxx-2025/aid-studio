# 版本说明

## 未发布

## v2.2.0（2026-09-23）

### 错误诊断

- 接口请求与任务、Skill 事件流增加请求编码关联；诊断开启时补充浏览器收到的原始错误、网络异常和流中断证据，过滤结构化及异常文本中的秘密字段、签名地址与系统提示词，不改变原有错误提示和业务重试。
- 诊断请求独立处理并合并状态查询，采集失败不触发登录跳转或重复业务请求；切换账号后丢弃旧登录会话的迟到证据。需配套服务端错误诊断接口；Web 本次无需 SQL。
- 项目详情按项目编号始终合并进行中的请求，强制刷新只绕过已完成结果缓存；成功和明确失败均短时复用，清理不存在项目的页面上下文时也保留短时失败缓存，避免流程壳层、页面挂载与 React 重渲染重复请求并生成重复诊断。纯 Web 修复，无需 SQL。

### 创作编辑弹窗

- 编辑场景、角色、道具图、分镜图及分镜视频弹窗的提示词输入上限跟随所选模型能力：普通文本读取 `maxPromptCharacters`，包含中日韩文字时优先读取 `maxPromptCharactersCjk`；模型未返回有效限制时仍按 100000 字符处理。输入区同步显示当前计数与上限，提交前使用相同规则校验。纯 Web 适配，无新增接口或数据库升级 SQL。

## v2.1.9（2026-09-21）

### 剧本创作 AI 对话

- 后台停用模型导致 Skill 请求明确拒绝时，清除未创建的运行恢复点并刷新可用模型，用户可直接改选模型继续对话；临时网络故障仍保留恢复入口。
- 对话中的停止按钮取消服务端运行；旧版已暂停接收的会话增加独立停止入口，停止完成后可发送新要求。无需 SQL。

### 模型与默认图片

- 修复未上传供应商图标时依赖外部图片地址的问题：公开供应商图标、Topaz 官方图标与默认头像随 Web 静态资源发布。自定义图片仍优先显示；本次 Web 变更无需数据库升级 SQL。

## v2.1.8（2026-09-18）

### 分镜生成参考素材

- 编辑分镜图片的普通生图继续支持只输入提示词，不要求上传图片；编辑分镜视频的图生视频参考图改为选填，未上传时由服务端回落已选分镜主图，多参视频允许不上传图片、音频或视频直接按提示词提交。已选素材仍按原字段传输，模型能力、数量和格式限制继续生效。
- 首尾帧生视频和分镜对话作图分别使用服务端强制首帧、参考图的专用接口，不将其误报为纯文本模式。此项仅改 Web，无新增后端代码或数据库升级 SQL。

## v2.1.6（2026-09-17）

### 批量视频生成

- 部分失败时展示任务返回的具体失败原因，成功的视频仍照常回填；恢复、续生与普通提交的提示保持一致。本次 Web 更新无需执行数据库升级 SQL。

## v2.1.3（2026-09-13）

### 公共目录与资产

- 未登录访客可正常请求官方风格、风格分类与 Skill 运行目录；Web 仅对这三个公开目录接口放行，其余 `/api/user/**` 接口仍要求登录，Skill 执行权限不变。本次 Web 更新无需执行数据库升级 SQL。

### 案例广场

- 案例卡片按项目自身画幅比例展示，不再固定为 `16:9`，也不使用成片、剧集视频或封面尺寸覆盖项目比例。本次 Web 更新无需执行数据库升级 SQL。

### 剧本创作

- 剧本 Skill 对话新增模型选择，并将所选模型随运行请求持久化；创建、恢复和重试均保持同一模型，服务端主 Skill 与全部子 Skill 统一继承该模型。模型列表以当前 Skill 的可用配置为准，本次 Web 更新无需执行数据库升级 SQL。
- 修复连续创建作品或恢复对话时，运行中、等待补充信息的 Skill 被错误显示为“运行失败”的问题；历史消息与实时消息按任务统一合并，避免重复卡片和完成后残留错误提示。
- 失败文档不再提示可带入剧本，等待补充信息的历史任务保留确认入口。本次修复无需执行数据库升级 SQL。

## v2.1.1（2026-09-12）

### 创作流程

- 缩短分镜视频多参数面板的参考素材导入文案，避免窄屏或复杂参数组合下入口文字拥挤。
- 修复流程化创作对话输入区未挂载装饰样式时，发送按钮失去右侧定位的问题；输入工具和发送操作现在始终保持稳定布局。

### 升级说明

- 本次 Web 修复不涉及数据库结构或初始化数据，无需单独执行升级 SQL；更新静态资源后建议强制刷新浏览器或清理站点缓存。

## v2.1.0（2026-09-12）

### 创作流程

- 编辑分镜视频的多参生成面板支持从本地和资产库导入参考视频；视频会登记为当前项目的分镜记录，并以可编辑的 `@视频N[名称]` 引用写入描述框，报价与生成请求按选择顺序提交参考视频记录 ID。模型能力、数量限制、素材条删除和文本引用删除保持双向一致，原有参考图与参考音频流程不变。

### 模型选择与生成参数

- 业务入口展示统一模型名称，参数选项使用当前业务能力；模型合并后可恢复旧模型编码和 ID 对应的选择，无法唯一匹配时不自动改选其他模型。
- 公共模型列表读取合并同请求键的进行中请求，重复打开或强制刷新仍复用正在执行的请求。

### 案例广场

- 恢复“发布至案例广场”的公共入口与交互，作品可以提交审核并查看发布状态。

### 充值与计费

- 修复充值中心关闭订单管理或消耗明细侧栏后透明遮罩残留、页面无法继续点击的问题；两个侧栏改为互斥状态并独立于主弹窗挂载，关闭时立即释放遮罩命中并在退场后销毁 Portal。

### 素材准备

- 角色、道具的形态编辑入口与主资产入口统一使用主图单选规则，覆盖生成记录、中间操作栏、导入确认、生成结果接管和重新打开后的状态恢复；场景继续支持多选，参考图多选不受影响。

### 我的作品

- 电影和剧集列表按服务端契约默认每页加载 20 条，滚动到底部自动加载下一页，并沿用统一的加载提示和卡片渐入效果；切换类型或搜索时隔离旧分页响应，避免结果串页。

### 首页与导航

- 修复登录弹窗、视频预览与编辑弹窗遮挡全局消息提示的问题，统一消息与通知的反馈层级。
- 首页主要导航预加载路由，并在首次跳转等待期间即时展示加载反馈；我的作品列表增加覆盖请求生命周期的全页加载状态。
- 流程页进入流程画布时增加导航中的即时反馈。

- 修复站点关键词或品牌图标未配置时，切换首页、我的作品和资产库触发页面卸载异常、导航失效的问题；站点标题、SEO 和图标统一由 React 管理。
- 未登记页面的 SEO 配置查询按正常空结果处理，保留页面默认信息。
- 移除左侧栏的开源和交流群入口及其浮层，保留教程、邀请和用户菜单。
- 移动端访问统一进入轻量提示页，并按开源站点视觉适配。
- 静态导出的 RSC 分段文件与客户端请求地址保持一致，避免纯静态部署访问页面时资源路径失配。

### 视频截帧

- 截帧弹窗按打开会话隔离视频与时间轴任务，关闭后再次打开重新初始化，旧任务不得覆盖新会话。
- 首尾帧选取与异步播放事件分离；解码失败不再回退到首帧，避免保存错误画面。
- 尾帧按微秒边界定位，不再以固定 30fps 偏移截取，兼容高帧率视频。

### 升级说明

- 本端不新增独立数据库结构；随服务端从 `v2.0.1` 升级时执行 `sql/v2.1.0.sql`，并同步更新服务端、后台管理端和 Web 静态资源。
- Web 静态资源更新后建议清理浏览器缓存或强制刷新；升级前仍应备份数据库、部署配置、证书和用户媒体目录。

## v2.0.1（2026-09-07）

### 创作流程

- 修复首页壳层重复切换后浮层挂载竞争、透明遮罩残留或导航失效的问题；登录、开源信息、交流群和用户菜单统一使用独立 Portal 容器。

- 修复音画同步列表在高分辨率下视频区域和行内内容被裁切的问题；预览区域与视频生成列表共用自适应高度布局，保留长台词内部滚动及生成状态展示。
- 优化场景角色道具图、分镜图、分镜视频和音画同步编辑器的高分辨率适配；内部面板、预览、Tab 和下拉控件统一随可用视口调整，浏览器缩放后自动回落，避免重复放大。
- 恢复我的作品与创作流程顶部的流程画布入口，以及作品/剧集绑定、流程连线、节点编辑、右键菜单和视频导出；保留节点主图展示、输入面板跟随与空格平移保护。
